桌面便條紙

Desktop Sticky Notes：放在 Windows 桌面上的便條紙，可以透過你自己的 Google 雲端硬碟在多台電腦之間同步。

功能

  • 便條紙直接貼在桌面上，可以拖曳、調整大小、換顏色、置頂、收合
  • 內容自動儲存在電腦上，不需要網路也能使用
  • 連線 Google 雲端硬碟後，文字、顏色與字體大小會在你的多台電腦之間自動同步
  • 同一張便條紙在兩台電腦同時被修改時，兩個版本都會保留，不會遺失內容

Google 帳號與資料

雲端同步是選用功能。連線後，程式只會存取你的電子郵件地址（用來顯示目前連線的帳號），以及 Google 雲端硬碟中本程式專屬的隱藏資料夾，看不到你雲端硬碟裡的其他檔案。資料只存在你的電腦和你自己的 Google 雲端硬碟，不會傳送給開發者或第三方。
